Pusheen the cat with laptop
===========================

Author:
  - bunivielle

Notes:
pusheen the cat is a cute character

This cursor set contains 2 cursors.

Files included:
  - Pusheen the Cat with Laptop Cursor--pointer--Sweez.cur
  - Pusheen the Cat with Laptop Cursor--cursor--Sweezy.cur

Installation:
  1. Right-click install.inf
  2. Select 'Install'
  3. Open Control Panel > Mouse > Pointers
  4. Select 'Pusheen the cat with laptop' from the Scheme dropdown
